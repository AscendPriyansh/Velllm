# Problem
Remote collaboration tools are often either too complex or separate communication and visual collaboration into different applications.

# Solution
Velllm combines a collaborative infinite whiteboard with real-time voice communication inside a shared room.

# Target users
## Primary:
Students
Developers
Small study groups

## Secondary:
Tutors
Interviewers
Small remote teams

# Core value proposition
Talk and draw together without switching tools.

# MVP
## Only:
Authentication
Room creation
Room sharing
Infinite whiteboard
Real-time drawing
Basic shapes/text
Undo/redo
Voice
Board persistence
