# Functional
## What the system must do.
FR-01 User can create a room
FR-02 User can join a room
FR-03 User can share a room link
FR-04 Users can draw
FR-05 Users can see other users' drawings
FR-06 Users can undo/redo
FR-07 Users can use microphone
FR-08 Board state is persisted
FR-09 User can leave room

# Non-functional
## How the system should behave.
NFR-01 Drawing should feel responsive
NFR-02 Real-time updates should have low latency
NFR-03 Audio should not be routed through application server
NFR-04 Board state should survive reconnects
NFR-05 System should handle small rooms reliably
